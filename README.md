# Asian Paints Complete Shade Catalogue & Comparison Tool 🎨

A fast, interactive, and responsive web app and PDF swatch book containing all **2,224 wall shades** from the Asian Paints Colour Spectra collection.

## Features ✨
- **Complete Dataset:** 2,224 verified shades with Shade Codes, Names, RGB, and HEX values.
- **Instant Search:** Search by code (e.g. `8499`, `0N68`, `L101`, `8010`) or name (`Eclipse`, `Peach Beach`).
- **Visual Family Filter Strip:** Filter across all 11 colour families (Blue, Brown, Green, Grey, Off-White, Orange, Pink, Purple, Red, White, Yellow).
- **Fullscreen Swatch Expansion:** Click any shade card to expand it to fill the entire screen with contrast-adjusted typography.
- **Side-by-Side Comparison:** Pin multiple shades to compare them in full-screen split view with left/right re-ordering.
- **Shareable Deep Links:** The URL query string (`?compare=8011,8563,0387` or `?shade=8010`) automatically updates and restores your exact comparison list.
- **Offline & Persistent:** Saved palettes persist in `localStorage`. Zero external dependencies or bloated scripts.
- **Printable PDF:** Includes `asian_paints_complete_shade_book.pdf` (57-page swatch book).
